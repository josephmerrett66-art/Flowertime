# Flower Shop

*Grow · Arrange · Sell.* A web version of the Flower Shop board game for 2–4 players. Play hot-seat on one device, against computer players, or both.

Open `index.html` in a browser to play. It is one self-contained file and only loads fonts from Google Fonts.

To change the rules while you playtest (starting coins, rents, flower values, water needed, dice rolls, win condition), use **Rules settings** in the game.
